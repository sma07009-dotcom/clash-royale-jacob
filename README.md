# Clash Royale Guide Hub

A Clash Royale fan site with these pages:

- Decks
- Strategies
- Synergies
- Glossary
- Coaching
- Trophy progress

## Run locally

```bash
pnpm install
pnpm run dev
pnpm run build
```

The site is built from the `app/` directory and runs with the commands above. A standalone homepage is also available at `index.html`.
